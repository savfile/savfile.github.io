使用前注意

  • 理论上 Neo Backup 支持所有应用（包括游戏和系统应用），但是否有效、安全、稳定，与 Neo Backup 开发者以及此教程无关。
  • 请自行承担使用 Neo Backup 带来的风险，包括但不限于数据丢失、系统崩溃、封号等。

准备

  • 已经 Root 的安卓手机（至少一台，安卓8 以上）
  • Neo Backup Github F-Droid
  1. 下载并安装 Neo Backup；
  2. 打开 Neo Backup，授予权限（MIUI、HyperOS 用户请关闭 MIUI优化）；
  3. 选择备份文件夹，不要选择主存储目录或“Download”文件夹，为你的备份创建一个独立的文件夹；
  4. 在主页选择你要操作的应用；
  5. Enjoy！

配置

点击右上角齿轮图标进入设置，这里介绍几个（我认为）比较重要的设置。

使用会话安装器

建议 安卓8 - 安卓12 的系统取消该选项。

启用特殊备份

启用特殊备份后，可以备份系统配置，但是其他系统不一定能用。在主页点击刷新后，等待一会，系统配置会出现在应用列表中。

注意事项

  • 备份和恢复时没有提示进度提示不明显，具体情况请自行判断。（2024/7/5 更新：有提示，但不多，不显示通知的系统看不到。）
  • 有时勾选还原 APK 选项后，会卡住或者报错。可以尝试在文件管理器里面直接安装 APK，取消勾选还原 APK 选项，仅还原数据。
  • 有时会出现无法正常读取备份文件的情况，可以清除 Neo Backup 应用数据，重新选择备份文件夹。
  • MTP 服务不可靠，建议使用 ADB 来传输备份文件。
